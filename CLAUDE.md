# Project Rules

## Git Operations
- Never run `git commit` or `git push` without explicit user permission — always ask first.

## Testing & Development
- Never run tests automatically (e.g. `npm test`, `npm run test`) — only when the user explicitly asks.
- Never start a dev server (e.g. `npm run dev`, `next dev`) or do CLI-based UI verification unless the user explicitly asks. These steps waste tokens.
